## Intent and boundary

Add engine-oriented runtime substrate depth on the analysis foundation:
routing, metering, automation playback, warp/render, plugin-chain execution,
offline render/freeze, and hardening — as reusable Signal-owned engine work,
not app-local glue. Ordering: routed mixer topology first, metering and
automation on that topology, warp/clip substrate after timing paths
stabilize, plugin-chain and offline render after the engine contract is
explicit, profiling and soak hardening last.

## Shipped outcomes

- Routed mixer graph, buses, and routing topology depth (`g03.001`).
- Runtime metering, loudness, and diagnostics export depth (`g03.002`).
- Automation engine and high-resolution parameter playback (`g03.003`).
- Tempo-map, stretch, and warp execution substrate (`g03.004`).
- Clip rendering, fades, and nondestructive processing depth (`g03.005`).
- Plugin device-chain execution, delay compensation, and state recall
  (`g03.006`).
- Offline render, freeze, and stem export pipeline (`g03.007`).
- Engine profiling, soak harnesses, and runtime fault hardening (`g03.008`).
