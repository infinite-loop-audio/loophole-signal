## Intent and boundary

Turn bounded Linux/plugin parity receipts into runtime-owned live session,
device, protocol, and workflow-adjacent depth: live Linux backend ownership
(ALSA, JACK, PipeWire session lifecycle), richer plugin protocol depth (LV2
worker/URID/patch, complex bus/pin negotiation), immersive routing and
monitoring breadth, vendor-protocol control-surface depth, and
runtime-owned preview/audition/media services — without promoting
product-local UX into shared runtime.

## Shipped outcomes

- Live Linux ownership: backend session lifecycle substrate, JACK transport
  and graph coordination, PipeWire/ALSA session-role and stream-policy
  parity (`g08.001`–`g08.003`).
- Plugin protocols: LV2 worker/URID/patch negotiation, complex pin-matrix
  and dynamic bus negotiation (`g08.004`–`g08.005`).
- Immersive and monitoring: object rendering and room policy, speaker
  deployment and fold-down, renderer capability negotiation and immersive
  export (`g08.006`–`g08.008`).
- Control surfaces: display/motor/haptic transport, scene mapping and safe
  action graphs (`g08.009`–`g08.010`).
- Preview and media: preview-output routing and audition-sink ownership,
  preview-browser queue and transform scheduling, asset/session transform
  persistence and cache placement (`g08.011`–`g08.013`).
- Live devices and acceptance: external MIDI device ownership, cross-backend
  device protocol acceptance, live-backend failure injection, immersive and
  control-surface acceptance, integrated acceptance, downstream-workflow
  readiness gate (`g08.014`–`g08.020`).
