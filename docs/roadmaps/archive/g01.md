## Intent and boundary

Turn the new Rust workspace from named package shells into a credible shared
DSP and engine runtime that Loophole can embed and other apps can reuse.
Dependency-first ordering: docs and package boundaries, then trust-edge
ownership, then core DSP and graph/runtime semantics, then host I/O and plugin
execution. Node-oriented mixer foundations early so console nodes, track lanes,
buses, and routing intent enter the engine contract before hosts build
workflow on flatter assumptions.
